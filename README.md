# Tianjiao Hao — Portfolio

A quiet, illustrated portfolio built with Next.js, React, TypeScript and Tailwind CSS, using the supplied original artwork.

Run `pnpm dev` and open http://127.0.0.1:5173.

For a production build: `pnpm build`, then `pnpm start`.

See [DEMO-GUIDE.md](DEMO-GUIDE.md) for content editing, asset relationships, motion, fonts and responsive behavior.
